🔄 Network Upgrade Flow: OIP → SafeSnap → Validator Updates

Key Actors in the Flow:
Guardians (Validators) Reality.eth Oracle SafeSnap Module NetworkUpgrade Contract Community Members
1
🗳️ OIP Creation on Snapshot
A Guardian creates a new OIP (Network Upgrade Proposal) on your existing Snapshot space
Includes: New commit hash + transaction payload for updateCommitHash(newHash)
⬇️
2
🏛️ Guardian Voting
All 20 Guardians (validators) vote on the OIP using Snapshot's gasless voting
Voting Power: Based on your existing stake/token holdings
⬇️
❓ Does OIP Pass?
Based on your governance thresholds
❌ OIP Rejected
Proposal fails - no on-chain action taken
3
🔮 Reality.eth Oracle Activation
SafeSnap automatically creates a Reality.eth question:
Question: "Did OIP-X pass on Snapshot with payload updateCommitHash('abc123')?"
Bond Required: Using your governance token
⬇️
4
⏰ 24-Hour Challenge Period
Community can dispute the Reality.eth question if they believe it's incorrect
Security: Escalation game prevents manipulation through economic incentives
⬇️
⚖️ Any Disputes?
🎯 Dispute Resolution
Reality.eth escalation game resolves disputes through community consensus
5
✅ Reality.eth Confirmation
Oracle confirms OIP outcome is correct - ready for execution
⬇️
6
🚀 Permissionless Execution
Anyone can now call execute() on the SafeSnap module
Tx Sender: Any community member (permissionless)
Gas Cost: Paid by the executor
⬇️
7
📜 Smart Contract Update
SafeSnap module calls NetworkUpgrade.updateCommitHash(newHash)
State Change: currentCommitHash = newHash
Event Emitted: CommitHashUpdated(newHash)
⬇️
8
👁️ Validator Monitoring
All 20 validator nodes detect the CommitHashUpdated event through blockchain monitoring
Technology: Web3 event listeners or polling mechanisms
⬇️
9
⬇️ Automated Download
Each validator automatically downloads docker-compose.yml from GitHub using the new commit hash
URL: https://raw.githubusercontent.com/your-repo/{commitHash}/docker-compose.yml
⬇️
10
🔄 Network Protocol Update
Validators restart their nodes with the new protocol version
Process: docker-compose down && docker-compose up
Result: Network-wide protocol upgrade completed

🎉 Upgrade Complete!

All validators are now running the new protocol version specified in the OIP
